# v0.4.2

## 핵심 변경

- 기본 비전 모델을 `gemma4:12b`에서 `qwen2.5vl:3b`로 변경했습니다.
- 앱 내 `모델 설치` 버튼과 배치 스크립트가 이제 `qwen2.5vl:3b`를 설치합니다.
- Ollama 요청 옵션을 안정성 우선으로 낮췄습니다.
  - `num_ctx`: 4096
  - `temperature`: 0
- 프레임 리사이즈 기본 폭을 1280px에서 960px로 낮췄습니다.

## 의도

전차선 주변 수목 여부와 간단한 역명 OCR은 매우 큰 VLM이 필요하지 않으므로, 납품 PC의 메모리 부담과 Ollama 500 오류 가능성을 낮추는 방향으로 조정했습니다.
