# v0.5.1

## 주요 변경

- 영상 등록 UX를 정리해 여러 영상 파일과 폴더 내 영상을 한 번에 추가할 수 있습니다.
- 가운데 `영상별 분석 로그`에서 분석할 영상을 선택한 뒤 선택 항목만 실행하도록 흐름을 바꿨습니다.
- 영상별 카드의 시작/중지를 하나의 버튼으로 통합하고, 개별 영상 제거 버튼을 추가했습니다.
- 여러 영상 분석 시 이벤트 병합이 영상별로 분리되도록 고쳐 서로 다른 영상의 같은 시간대 이벤트가 섞이지 않습니다.
- 주변 산, 원경 숲, 배경 녹색이 전차선 근처에 보인다는 이유만으로 위험도를 높이지 않도록 지장수목 판정 지시를 강화했습니다.
- 리포트에서 확률 숫자 표기를 제거하고 위험도 `높음`, `중간`, `낮음` 중심으로 보이도록 정리했습니다.

## 검증

- `scripts/test.cmd` 기준 26개 테스트를 통과했습니다.
