# v1.0.1

Windows 11 installer reliability patch.

## Fixed

- Rebuilt the Windows installer after detecting that the v1.0.0 artifact could exit before setup started.
- Changed Windows installation to a per-user location so setup no longer requires an administrator prompt.
- Removed non-ASCII setup metadata that could render incorrectly when the script encoding was misdetected.
- Disabled solid compression to keep the large bundled-runtime installer responsive while extracting files.
- Added an automatic real install/uninstall smoke test to the Windows packaging pipeline.

## Included

- Bundled Ollama and FFmpeg runtimes; no separate Ollama installation is required.
- In-app vision model download, hardware recommendation, installation, and selection.
- Model-specific prompt harnesses for supported Qwen3-VL and Gemma 4 variants.
