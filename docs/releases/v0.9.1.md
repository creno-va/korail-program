# v0.9.1

## Changes

- Updated PDF reports to follow the supplied catenary obstruction tree field report format.
- Arranged up to two analysis frames per A4 page with risk level, timecode, OCR-estimated section, and evidence.
- Removed shooting date, business office, kilometer position, and other fields that cannot be derived reliably from video analysis.
- Added an in-app PDF viewer that opens immediately after saving and supports scrolling, zooming, and fit-to-width.
- Refined workflow copy and project documentation for the new report experience.
