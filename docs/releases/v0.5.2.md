# v0.5.2

## 주요 변경

- 영상을 여러 개 등록하더라도 분석은 선택한 영상 하나만 실행되도록 되돌렸습니다.
- 로컬 VLM 안정성을 위해 한 영상이 준비/분석 중일 때 다른 영상의 시작 버튼을 잠급니다.
- 모델 설치 확인 중인 상태를 `준비`로 표시해 분석 중지 상태처럼 보이던 혼선을 줄였습니다.
- 가운데 `영상별 분석 로그` 선택 동작을 단일 선택으로 정리했습니다.
- 기본 모델 안내와 설치 스크립트 기본값을 `qwen3-vl:8b`로 통일했습니다.
- README, 패키징 문서, 파이프라인/결정 문서의 오래된 Gemma/Qwen2.5 기본값 문구를 정리했습니다.
