# v0.4.0

## 핵심 변경

- Windows 설치판 기준으로 Python/Ollama/FFmpeg 선설치 없이 실행되는 경로를 유지합니다.
- 역명 OCR 기본 백엔드를 PaddleOCR에서 `gemma4:12b` 기반 VLM OCR로 전환했습니다.
- GUI의 `분석 시작` 버튼을 실제 배치 분석 파이프라인에 연결했습니다.
- 대기열, 영상별 로그, 이벤트 결과, 로그 패널을 커스텀 카드 UI로 재구성했습니다.
- HTML/Markdown 리포트에 OCR 역명 관측 수와 이벤트 구간을 표시합니다.

## 설치 후 흐름

1. `KorailAnalyzerSetup-0.4.0.exe` 설치
2. 앱 실행
3. `모델 설치` 버튼으로 `gemma4:12b` 다운로드
4. 영상 추가
5. `분석 시작`

## 참고

- 분석 중 OCR 실패는 전체 분석 실패로 처리하지 않고 `observations.json`의 `failures`에 `stage: "ocr"`로 기록합니다.
- PaddleOCR은 선택형 백엔드로 남아 있지만 기본 설치판 기능에는 필요하지 않습니다.
