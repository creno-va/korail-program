# v1.0.0

## Changes

- Replaced the OpenAI GPT API frame judge and station OCR path with fully local Ollama vision inference.
- Removed API-key storage, OpenAI client code, certificate dependencies, and API-key helper scripts.
- Bundled the complete Ollama runtime alongside FFmpeg in Windows and macOS application packages.
- Added an in-app model manager with download progress, installed-state detection, model selection, and persistent per-user model storage.
- Added local image-capable Gemma 4 E2B/E4B/12B and Qwen3-VL 2B/4B/8B options.
- Added OS, CPU, RAM, GPU/VRAM, and free-storage detection with a conservative hardware recommendation shown at the top of the model list.
- Added dedicated per-model judge and OCR harnesses with JSON Schema output, family-specific decoding settings, and size-specific verification instructions.
- Isolated the app's Ollama server on `127.0.0.1:11435`, stored models under the Korail Analyzer user-data directory, and disabled Ollama cloud execution.
- Updated the CLI, reports, development installers, packaging scripts, tests, and documentation for offline operation.
