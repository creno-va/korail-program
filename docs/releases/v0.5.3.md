# v0.5.3

## 주요 변경

- macOS 설치 마법사 빌드 스크립트 `scripts/package_macos.sh`를 추가했습니다.
- macOS용 PyInstaller `.app`, Apple Installer `.pkg`, 배포용 `.dmg` 산출물을 생성할 수 있습니다.
- macOS 앱 내부에 Ollama runtime, `llama-server`, FFmpeg/FFprobe를 함께 묶는 경로를 추가했습니다.
- GitHub Actions `Build macOS installer` workflow를 추가해 arm64와 Intel용 macOS pkg/dmg를 릴리즈 asset으로 업로드할 수 있습니다.
- 런타임 탐색 로직이 Windows `.exe`뿐 아니라 macOS `ollama`, `llama-server`, `ffmpeg`, `ffprobe` 번들 경로도 인식합니다.
- macOS 사용자 데이터 경로를 `~/Library/Application Support/KorailAnalyzer`로 분리했습니다.

## 검증

- `scripts/test.cmd`
- `python -m compileall -q src tests`
- `korail-analyzer --version`
- Windows 환경에서는 macOS `.pkg`/`.dmg`를 직접 빌드할 수 없으므로 GitHub Actions macOS runner에서 빌드합니다.
