# v0.2.0

## Highlights

- 기본 VQA 모델을 `gemma4:12b`로 변경했습니다.
- 앱 내에서 Ollama 모델 설치를 실행할 수 있는 `모델 설치` 버튼을 추가했습니다.
- 루트/지정 경로 영상을 일정 간격으로 샘플링해 VQA 후 HTML/Markdown/JSON 리포트를 생성하는 배치 분석 명령을 추가했습니다.
- GitHub Release에서 바로 실행 가능한 Windows/macOS standalone 설치 스크립트를 추가했습니다.
- 루트 샘플 영상은 테스트 데이터 위치인 `tests/data/videos/`로 이동했습니다.

## Install

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File .\install_windows.ps1
```

macOS:

```sh
sh install_macos.sh
```

Both installers download the release source, install the Python app, prepare FFmpeg/Ollama when possible, and pull `gemma4:12b`.
