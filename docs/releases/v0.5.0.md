# v0.5.0

## 주요 변경

- 모델 설정 모달을 추가했습니다.
- `qwen2.5vl:3b`, `qwen3-vl:4b`, `qwen3-vl:8b`, `qwen2.5vl:7b` 중 선택/설치할 수 있습니다.
- 설치된 모델은 모달에서 바로 사용 모델로 선택할 수 있습니다.
- PC RAM/GPU 사양을 기준으로 추천 모델 배지를 표시합니다.
- 기본 모델을 `qwen3-vl:8b`로 상향했습니다.
- 핵심 액션을 별도 컨테이너로 정리해 모델 설정, 선택 영상 분석, 리포트 열기를 더 잘 보이게 했습니다.
- 여러 영상을 추가해도 영상별 카드에서 개별 시작/중지가 가능하도록 바꿨습니다.
- 분석 중지는 현재 모델 호출이 끝난 뒤 다음 프레임으로 넘어가기 전에 적용됩니다.
- 프롬프트를 보정해 선로 주변 일반 식생과 전차선 근접 식생을 더 엄격히 구분하도록 했습니다.

## 참고

`qwen3-vl:8b`는 정확도 우선 기본값입니다. 16GB RAM과 8GB급 NVIDIA GPU에서 우선 권장하며, 속도가 부담스러우면 모델 설정에서 `qwen3-vl:4b` 또는 `qwen2.5vl:3b`를 선택하세요.
