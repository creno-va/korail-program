# v0.7.0

## Changes

- Redesign the desktop workspace around a three-column video workflow: video library, selected video detail, and frame results.
- Add embedded video playback with hover controls and frame-to-timestamp seeking.
- Simplify the video sidebar, model settings, analysis progress, statistics, and report actions with a consistent solid visual system.
- Replace separate analysis start and stop controls with one state-aware action.
- Generate a printable PDF report with exactly one suspicious frame per A4 page and add Save As support in the app.
- Preserve every suspicious capture in the result sidebar instead of collapsing captures into a single event card.
- Centralize video file discovery and keep cancellation separate from per-frame analysis failures.
- Fix duplicate font packaging metadata and expand automated coverage for UI selection, cancellation, file discovery, and PDF pagination.
