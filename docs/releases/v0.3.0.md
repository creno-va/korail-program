# v0.3.0

## Highlights

- Windows 실행파일 배포를 위한 PyInstaller 설정을 추가했습니다.
- Inno Setup 기반 설치 마법사를 추가했습니다.
- `scripts/package_windows.ps1` / `scripts/package_windows.cmd`로 앱 번들과 설치 exe를 재현 가능하게 빌드할 수 있습니다.
- 설치 마법사는 시작 메뉴 바로가기, 선택형 바탕화면 바로가기, 설치 후 실행 옵션을 제공합니다.

## Assets

- `KorailAnalyzerSetup-0.3.0.exe`: Windows 설치 마법사
- `install_windows.ps1`: 릴리즈 소스 기반 Windows 설치 스크립트
- `install_macos.sh`: 릴리즈 소스 기반 macOS 설치 스크립트
