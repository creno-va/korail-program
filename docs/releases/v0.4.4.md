# v0.4.4

## 주요 변경

- GUI 기본 분석을 고속 스캔 기준으로 조정했습니다.
- VQA 샘플링 기본값을 10초에서 30초로, OCR 샘플링 기본값을 30초에서 120초로 변경했습니다.
- VQA 입력 이미지 폭을 960px에서 768px로 낮춰 로컬 VLM 처리 부담을 줄였습니다.
- 분석 엔진에 프레임 단위 진행률 콜백을 추가해 45%에서 멈춘 것처럼 보이던 UI를 수정했습니다.
- 실행 로그 패널을 스크롤 가능한 커스텀 영역으로 변경했습니다.
- Ollama 서버의 반복 내부 로그는 에러성 로그만 표시하도록 줄였습니다.

## 참고

이 버전은 저사양 PC에서 우선 끝까지 확인 가능한 기본값을 목표로 합니다. 더 촘촘한 탐지가 필요하면 추후 UI에 정밀 스캔 옵션을 분리하는 방향이 적절합니다.
