# v0.4.3

## 핵심 변경

- Windows 설치 마법사에 Ollama `lib/ollama` runner 디렉터리를 함께 포함합니다.
- `llama-server.exe`, `libllama*.dll`, CPU/GPU backend DLL 누락으로 발생하던 `llama-server binary not found` 오류를 수정했습니다.
- 패키징 스크립트가 `ollama.exe`만 있는 상태를 정상 런타임으로 보지 않도록 검증을 강화했습니다.
- 앱 런타임 점검이 깨진 Ollama 번들을 `Ollama 손상` 상태로 표시합니다.

## 참고

이 버전부터 설치 파일 크기가 커집니다. 대신 별도 Ollama 설치 없이 설치 마법사만으로 모델 실행에 필요한 Ollama 보조 바이너리까지 함께 배포합니다.
