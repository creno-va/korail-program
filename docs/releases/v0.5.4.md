# v0.5.4

## 주요 변경

- macOS `Ollama.app` 리소스 구조를 반영해 번들 Ollama 검증 기준을 보정했습니다.
- Windows는 기존처럼 `llama-server.exe` 존재 여부까지 확인하고, macOS는 `ollama` 실행 파일과 앱 리소스 디렉터리를 기준으로 확인합니다.
- macOS 설치 마법사 빌드 스크립트가 공식 Ollama 앱 리소스를 통째로 묶을 수 있도록 수정했습니다.

## 검증

- `scripts/test.cmd`
- `python -m compileall -q src tests`
- `korail-analyzer --version`
- GitHub Actions `Build macOS installer` workflow로 macOS pkg/dmg 빌드를 검증합니다.
