# v0.4.1

## 핵심 변경

- 분석 완료 후 진행률 막대 색상을 상태별로 표시합니다.
  - 정상 완료: success
  - 일부 프레임 실패: warning
  - 모델 호출 반복 실패로 중단: error
- 이벤트가 없을 때 이벤트 영역에 “걸리는 이벤트 없음” 안내를 표시합니다.
- Ollama `HTTP 500` 오류의 응답 본문을 리포트와 `observations.json`에 남깁니다.
- 이미지 + structured JSON 호출에서 Ollama가 5xx를 반환하면 `format=json` 없이 한 번 자동 재시도합니다.
- Judge 모델 호출이 3회 연속 실패하면 전체 영상을 끝까지 낭비하지 않고 조기 중단 리포트를 생성합니다.

## 확인 포인트

- `HTTP 500`이 계속 발생하면 새 리포트의 상단 `처리 상태`에 실제 Ollama 오류 메시지가 표시됩니다.
- 메모리 부족, 모델 미설치, 이미지 입력 미지원 같은 원인은 더 이상 단순 `Internal Server Error`로만 숨겨지지 않습니다.
