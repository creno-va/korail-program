# v0.6.0

## Changes
- Replace the default local Ollama VLM frame judge with OpenAI GPT vision VQA.
- Add an OpenAI Responses API client that sends sampled frames as base64 image data URLs.
- Move GPT station OCR onto the same OpenAI API path while keeping the OCR pipeline separate from judge.
- Replace model install UX with GPT API settings and local API key storage.
- Add `.env`/`.env.local` loading and helper scripts for setting `OPENAI_API_KEY`.
- Stop bundling Ollama and `llama-server` in Windows/macOS installers; FFmpeg remains bundled.
- Update docs, model catalog, install scripts, and batch defaults to `gpt-5.6-terra`.
