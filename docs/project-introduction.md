# 01. 프로젝트 소개

## 코레일 지장수목 분석 프로그램

철도 주행 영상을 AI로 분석해 전차선로 인접 지장수목을 탐지하고, 검토 가능한 프레임과
PDF 보고서로 정리하는 데스크톱 프로그램

| 구분 | 내용 |
| --- | --- |
| 작업 기간 | 2026.07 - 2026.08 |
| 담당 범위 | 기획, UX/UI 설계, 분석 파이프라인 개발, 패키징, 테스트 |
| 기술 스택 | Python, PySide6, OpenAI Responses API, FFmpeg, ReportLab, SQLite |

# 02. 개요와 핵심 기능

## 개요

철도 주행 영상을 사람이 처음부터 끝까지 확인하던 반복 업무를 줄이기 위해 개발한
AI 기반 분석 도구입니다. 영상을 일정 간격으로 샘플링하고 GPT Vision으로 전차선 주변
수목의 존재 여부와 위험도를 판정합니다. 역명 OCR 결과는 영상 타임라인의 운행 구간으로
변환하며, 탐지 프레임과 판단 근거는 현장 검토에 바로 활용할 수 있는 PDF 보고서로
생성합니다.

## 담당 역할

- 업로드, 분석, 보고서로 이어지는 3단계 사용자 흐름과 상세 분석 화면 설계
- FFmpeg 프레임 샘플링, GPT VQA, VLM OCR, 이벤트 병합 파이프라인 구현
- 한글 영상명과 OCR 추정 구간을 포함한 표지·프레임별 PDF 보고서 개발
- Windows/macOS 독립 실행형 설치 패키지와 GitHub Actions 릴리즈 자동화 구성
- 단위 테스트, 오프스크린 UI 캡처, PDF 텍스트 추출·렌더링 검증 체계 구축

## 핵심 기능

- 앱 전체 영역 영상 파일·폴더 드래그앤드롭
- 영상별 선택, 재생, 분석 시작·정지 및 진행률 확인
- GPT Vision 기반 지장수목 위험도 판정과 근거 문장 생성
- VLM OCR 기반 역명 관측 및 `역간 구간/역 인근/미확인` 라벨링
- 탐지 프레임, 통계, 타임코드, 검수 상태를 포함한 PDF 보고서 저장

# 03. 문제 해결과 아키텍처

## 문제 해결

프레임 단위 판정은 동일한 수목을 여러 건으로 중복 탐지할 수 있어 시간 간격과 영상 ID를
기준으로 연속 프레임을 하나의 이벤트로 병합했습니다. OCR 관측 사이에만 구간을 만들던
기존 방식은 영상 앞뒤가 `구간 미확인`으로 남는 문제가 있어, 첫 관측 이전부터 마지막 관측
이후까지 전체 타임라인을 덮도록 구간 매핑 하네스를 보정했습니다. 또한 VLM이 역명을
구조화 필드가 아닌 원문으로 반환해도 역명 패턴을 보조 추출하도록 폴백을 추가했습니다.

PDF는 Pretendard GOV 글꼴을 내장하고 Unicode NFC 정규화와 UTF-8 mojibake 복구를 적용해
한글 영상명이 깨지지 않도록 했습니다. 표지에는 분석 대상과 주요 통계, OCR 추정 구간을
요약하고 이후 각 탐지 프레임을 한 페이지씩 구성해 출력물의 가독성을 높였습니다.

## 아키텍처

```text
영상 파일/폴더
  -> FFmpeg 메타데이터 확인 및 프레임 샘플링
  -> GPT Vision 위험도 판정 + VLM 역명 OCR
  -> OCR 타임라인 구간 매핑
  -> 연속 프레임 이벤트 병합
  -> 캡처·통계·PDF/HTML/Markdown/JSON 산출
  -> PySide6 메인/상세 화면에서 검토 및 저장
```

GUI, 분석 파이프라인, OCR, 이벤트 병합, 저장소, 보고서 생성기를 모듈로 분리해 개별 테스트와
교체가 가능하도록 구성했습니다. API 오류, 분석 취소, 지원하지 않는 파일, 구간 미확인 등
실제 운영 중 발생할 수 있는 예외 상태를 명시적으로 처리합니다.
