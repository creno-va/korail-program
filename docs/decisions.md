# 프로젝트 결정 사항

## D-001. Python과 PySide6

분석 모듈, FFmpeg 연동, PDF 생성 코드와 데스크톱 UI를 하나의 Python 코드베이스로 유지합니다. 납품본은 PyInstaller로 묶어 대상 PC의 Python 설치에 의존하지 않습니다.

## D-002. 로컬 Ollama VLM

프레임 판정과 역명 OCR의 기본 경로는 OpenAI API가 아니라 앱에 포함된 Ollama 런타임입니다. 사용자 영상이 외부로 전송되지 않고 API key·사용료·인터넷 연결 없이 분석할 수 있기 때문입니다.

Ollama는 앱 전용 포트와 모델 폴더를 사용합니다. 외부에 이미 설치된 Ollama는 개발 편의를 위한 fallback이며, 정식 설치본은 번들 런타임을 우선합니다.

## D-003. 모델은 설치 후 다운로드

모델 파일은 수 GB이므로 설치 마법사에 넣지 않습니다. 앱이 시스템 사양과 저장 공간을 보여주고 추천 모델을 최상단에 배치하며, 사용자가 Gemma 4 또는 Qwen3-VL 모델을 직접 설치·선택합니다.

## D-004. 모델별 하네스

하나의 범용 프롬프트 대신 Qwen과 Gemma 4의 시각 grounding·샘플링 특성에 맞춘 하네스를 둡니다. Judge와 OCR은 서로 다른 system/user 프롬프트 및 JSON Schema를 사용합니다.

## D-005. 후보 생성 도구

로컬 VLM 결과는 안전 진단의 최종 근거가 아니라 검수할 후보 이벤트입니다. 불확실한 중간 위험도와 처리 실패를 리포트에 남겨 사람이 확인할 수 있게 합니다.
