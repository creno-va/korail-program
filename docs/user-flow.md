# 사용자 플로우

## 1. 최초 실행

설치 마법사로 앱을 설치합니다. Python, FFmpeg, Ollama 또는 API key를 별도로 준비할 필요가 없습니다.

## 2. 로컬 AI 모델

사이드바의 `로컬 AI 모델`을 누릅니다. 모달 상단에서 OS, CPU, RAM, GPU/VRAM, 저장 여유 공간과 추천 사유를 확인합니다. 추천 모델은 목록 최상단에 표시됩니다.

원하는 Gemma 4 또는 Qwen3-VL 모델의 `설치`를 누르면 진행률이 표시됩니다. 설치가 완료된 모델은 즉시 선택되며, 다른 설치 모델의 `사용` 버튼으로 언제든 전환할 수 있습니다.

## 3. 영상 추가와 분석

영상 파일·폴더를 추가하고 분석을 시작합니다. 선택 모델이 없으면 모델 모달이 열립니다. 앱은 번들 Ollama 서버를 시작한 뒤 프레임 Judge와 VLM OCR을 로컬에서 실행합니다.

## 4. 결과 확인과 저장

위험 후보 카드와 캡처를 검수하고 PDF 리포트를 저장합니다. 영상·프레임·모델 응답은 외부 API로 전송되지 않습니다.

## 예외 상태

- Ollama 손상/없음: 정식 설치 마법사로 다시 설치합니다.
- 모델 미설치: 모델 모달에서 설치합니다.
- 저장 공간 부족: 더 작은 모델을 선택하거나 공간을 확보합니다.
- RAM/VRAM 부족: 추천 모델 또는 더 작은 Qwen 모델로 전환합니다.
- FFmpeg 없음: 정식 설치본을 다시 설치합니다.
