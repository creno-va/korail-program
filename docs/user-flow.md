# 사용자 플로우

## 1. 최초 실행

사용자는 설치 마법사로 앱을 설치한 뒤 바로 실행한다.

첫 화면에서 확인해야 하는 핵심 상태:

- API key 설정 여부
- 선택된 GPT 모델
- 영상 대기열
- 영상별 분석 로그
- 리포트 열기 버튼

## 2. API 설정

사용자는 `API 설정`에서 다음을 입력하거나 선택한다.

- OpenAI API key
- GPT vision 모델

대체 경로:

- `OPENAI_API_KEY` 환경변수
- `.env` 또는 `.env.local`

API key는 git, 릴리즈, 리포트에는 기록하지 않는다.

## 3. 영상 추가

사용자는 mp4, avi, mov, mkv 파일을 드래그하거나 파일 선택 버튼으로 추가한다.

앱은 다음을 표시한다.

- 영상 파일명
- 파일 크기
- 분석 대기/진행/완료/실패 상태
- 영상별 시작/중지 액션

## 4. 분석 시작

사용자는 영상별 로그 카드에서 분석할 영상을 선택하고 `선택 영상 분석`을 누른다.

앱 동작:

```text
영상 메타데이터 확인
 -> FFmpeg 프레임 샘플링
 -> GPT OCR
 -> GPT VQA Judge
 -> 타임코드 기준 병합
 -> 캡처 저장
 -> HTML/Markdown/JSON 리포트 생성
```

한 번에 한 영상만 분석한다. 여러 영상을 동시에 등록할 수 있지만 시작/중지 제어는 영상별로 수행한다.

## 5. 결과 확인

분석 완료 후 앱은 다음을 표시한다.

- 이벤트 수
- 영상별 완료 상태
- 캡처 프레임
- 위험도
- 타임코드
- 근거 문장
- OCR 기반 구간 정보

위험 이벤트가 없으면 이벤트 영역에 “기준 위험 이상의 이벤트 없음” 안내를 표시한다.

## 6. 리포트 열기

사용자는 `리포트 열기`로 HTML 리포트를 확인한다.

리포트 산출물:

- `report.html`
- `report.md`
- `observations.json`
- `events.json`
- `captures/`

## 예외 상태

### API key 없음

- 분석 시작 불가
- API 설정 창으로 이동
- 환경변수 또는 앱 설정 저장 안내

### OpenAI API 오류

- 반복 실패 시 분석 중단
- 리포트와 로그에 HTTP status 및 오류 요약 기록
- 401: API key 확인
- 429: rate limit 또는 quota 확인
- 모델 접근 오류: 선택 모델 변경 안내

### FFmpeg 없음

- 설치판에서는 번들 FFmpeg를 우선 사용
- 개발 실행에서는 시스템 FFmpeg 또는 `FFMPEG_PATH` 설정 필요

### 위험 이벤트 없음

- 진행률 100%와 success 상태 표시
- 이벤트 영역에 “기준 위험 이상의 이벤트 없음” 안내 표시
- 리포트는 정상 생성
