# 사용자 플로우

## 대상 사용자

철도 시설/전차선로 관리 담당자가 주행 영상을 넣고 지장수목 의심 구간을 빠르게 확인한다.

사용자는 AI 모델, OCR, 프레임 추출의 세부 동작을 알 필요가 없다. 화면에서는 영상 등록, 분석 진행, 결과 확인, 리포트 저장이 명확해야 한다.

## 메인 플로우

```text
1. 프로그램 실행
2. 영상 파일 등록
3. 분석 설정 확인
4. 분석 시작
5. 진행률 확인
6. 결과 목록 확인
7. 캡처/영상 시점 확인
8. 필요 시 수동 검수
9. PDF/Excel 리포트 내보내기
10. 분석 이력 재조회
```

## 1. 프로그램 실행

초기 화면 구성:

- 좌측: 영상 대기열
- 중앙: 분석 결과 목록 또는 빈 상태 화면
- 우측: 선택한 이벤트 상세 정보
- 하단: 진행률, 로그, 현재 작업 상태

빈 상태에서는 파일 드래그 앤 드롭 영역과 파일 선택 버튼만 명확히 보여준다.

## 2. 영상 파일 등록

사용자 행동:

- mp4, avi 등 영상 파일 드래그 앤 드롭
- 파일 선택 버튼으로 다중 선택

프로그램 동작:

- 파일 존재 여부 확인
- 확장자 확인
- 영상 길이, 해상도, fps 추출
- 대기열에 등록
- 이미 등록된 파일은 중복 등록 경고

대기열 항목 표시:

- 파일명
- 영상 길이
- 해상도
- 상태: 대기/분석 중/완료/실패
- 탐지 건수

## 3. 분석 설정 확인

기본 설정:

- 프레임 judge 샘플링: 1fps
- OCR 샘플링: 1fps
- 위험도 기준: 기본값
- 캡처 저장: 이벤트당 대표 3-5장
- 결과 저장 위치: 프로그램 데이터 폴더

고급 설정:

- 역명 오버레이 ROI
- Judge 대상 ROI
- 위험도 임계값
- 모델 서버 경로 또는 실행 방식
- OCR 언어/모델 경로

## 4. 분석 시작

사용자 행동:

- [분석 시작] 클릭

프로그램 동작:

```text
영상 메타데이터 확인
 -> OCR 파이프라인 시작
 -> Judge 파이프라인 시작
 -> 타임코드 기준 결과 병합
 -> 이벤트 생성
 -> 캡처 이미지 저장
 -> SQLite 저장
```

분석 중 사용자는 다음을 볼 수 있어야 한다.

- 전체 진행률
- 현재 파일 진행률
- 현재 단계: 프레임 추출/OCR/Judge/병합/리포트 준비
- 예상 남은 시간
- 오류 및 경고 로그

## 5. 결과 목록 확인

결과 목록 기본 정렬:

1. 위험도 높은 순
2. 영상 타임코드 빠른 순

목록 항목:

- 위험도: 상/중/하
- 구간: 시작 역명 -> 끝 역명
- 영상 타임코드: 00:12:34 - 00:13:02
- 판단 요약
- 캡처 개수
- 검수 상태: 미확인/확인/오탐/보류

예시:

```text
[위험도 상] 일로역 -> 몽탄역 | 00:12:34 - 00:13:02
대나무형 수목 군락이 우측 전차선로 주변에 근접해 보임
[캡처 4장] [해당 시점 보기] [검수 상태 변경]
```

## 6. 이벤트 상세 확인

사용자 행동:

- 결과 목록에서 이벤트 클릭

프로그램 동작:

- 대표 캡처 표시
- 원본 프레임 표시
- Judge bbox_hint 또는 시각 표시 오버레이
- OCR로 매핑된 구간 정보 표시
- 전후 프레임 이동 가능
- 해당 영상 타임코드로 이동

상세 화면 정보:

- 영상 파일명
- 구간명
- 시작/종료 타임코드
- 위험도
- Judge 판단 근거
- OCR 인식 신뢰도
- 수동 검수 상태
- 리포트 포함 여부

## 7. 수동 검수

사용자는 각 이벤트를 다음 상태로 바꿀 수 있다.

- 미확인
- 확인
- 오탐
- 보류

수동 검수 결과는 리포트에 반영한다.

오탐으로 표시된 이벤트는 기본 리포트에서 제외하되, 설정에서 포함 가능하게 한다.

## 8. 리포트 내보내기

사용자 행동:

- [리포트 내보내기] 클릭
- PDF, Excel 중 선택

프로그램 동작:

- 분석 개요 생성
- 구간별 이벤트 목록 생성
- 위험도별 요약 생성
- 캡처 이미지 삽입
- 검수 상태 반영
- 파일 저장

리포트 포함 항목:

- 분석 대상 영상
- 분석 일시
- 노선명
- 총 탐지 건수
- 위험도별 건수
- 구간별 상세 목록
- 타임코드
- 판단 근거
- 캡처 이미지
- 검수 상태

## 예외 플로우

### 영상 파일을 읽을 수 없음

- 상태를 실패로 표시
- 로그에 원인 기록
- 다음 파일 분석은 계속 진행

### OCR 실패

- 해당 시간대 구간을 "구간 미확인"으로 표시
- 전후 안정 인식값으로 보간 시도
- 보간 실패 시 수동 입력 가능

### Judge 실패

- 해당 프레임을 재시도 대기열에 등록
- 반복 실패 시 "판정 실패"로 기록
- 전체 분석은 계속 진행

### 로컬 모델 서버 미실행

- 분석 시작 전 상태 점검에서 차단
- 사용자에게 모델 서버 시작 버튼 또는 설정 이동 제공

### 저장 공간 부족

- 분석 시작 전 예상 산출물 용량 경고
- 분석 중 감지 시 안전 중단
- 이미 생성된 DB/캡처는 보존
